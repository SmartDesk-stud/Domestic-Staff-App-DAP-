| Field | Detail |

| **Project window** | July 1, 2025 – October 31, 2025 |
| **Methodology** | Hybrid (Agile + Waterfall) |
| **Team Lead** | Maryam Abubakar |
| **Associate Project Manager / Author** | Morenikeji Bankole |
| **Status** | Project Closed |

The Domestic Staffing Platform connects customers who need domestic staff with service personnel, through agents who register and place them, with an administrator overseeing the platform. The project delivered a web platform and iOS and Android apps for four user roles: Admin, Customer, Agent and Service Personnel.

This folder holds the project management artifacts. Planning documents read as they stood when issued; documents with a "final" version also record the actual outcomes.

## Conventions

- Findings are referenced as **L-**, **A-**, **C-**, **S-** (landing page, agent, customer, service personnel), risks as **R-xx**, change requests as **CR-xx**, UAT scenarios as **UAT-xx**.
- Priorities: **P1** (blocks a core journey), **P2** (workaround or usability), **P3** (cosmetic).
- Work was tracked in ClickUp; this repository holds the formal record.
