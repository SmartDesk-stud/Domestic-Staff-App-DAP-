## 1. Reporting Approach

Reports are issued at each milestone, which matches how the project runs: one report per role increment, then hardening and release. Health uses **Green** (on track), **Amber** (at risk, mitigation under way) and **Red** (off track, escalation needed). Each report covers schedule, scope, quality, risks and next steps.

## 2. Report Template

| Section | Content |
| --- | --- |
| Header | Report number, date, phase and iteration |
| Health | Overall, schedule, scope, quality |
| Accomplished | Work finished since the last report |
| Next | Work for the coming period |
| Risks and issues | New or changed items with owners |
| Decisions needed | From the Team Lead |
| Changes | Change requests raised or decided |
