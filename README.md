# Domestic-Staff-App-DAP-

Project management artifacts for the Domestic Staffing Platform (July–October 2025): charter, WBS, RACI, risk register, change log, defect log, UAT, release plan, status reports and closure report. Hybrid Agile + Waterfall, tracked in ClickUp.

The platform connects customers who need domestic staff with service personnel, through agents who register and place them, with an administrator overseeing it. The project delivered a web platform and iOS and Android apps for four user roles, built in a staggered pipeline of design, build, QA and client presentation. It ran from July 1 to October 31, 2025, with the Team Lead Maryam Abubakar and the Associate Project Manager Morenikeji Bankole.
